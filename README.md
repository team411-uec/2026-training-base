# 研修 最終成果開発用ベース集

研修の最終成果開発で使う **ベース（土台）アプリ** をまとめたリポジトリです。
研修生（個人またはチーム）は、好きなベースを選んで段階的に完成・拡張していきます。

どちらのベースも共通の作り方をしています。

- **画面は HTML 1枚**、プログラムは **データ層 → 描画層 → イベント層** の3つに分割。
- **配布時はわざと「未完成」**。まず「ステップ1」で描画層を実装して画面に反映させ、
  そのあと自由に拡張する（詳細は各フォルダの README を参照）。
- 学んだ範囲（TypeScript / 基本 HTML / DOM 操作）だけで作れるようにしてある。

## 収録しているベース

| フォルダ | アプリ | 概要 |
| --- | --- | --- |
| [`omikuji/`](./omikuji/) | おみくじ | ボタンを押すとおみくじを引ける。比率・履歴・演出などへ拡張。 |
| [`paint/`](./paint/) | ドット絵ペイント | マス目をクリックして塗る。パレット・バケツ塗り・Undo・アニメなどへ拡張。 |

## 起動方法

各アプリはそれぞれ独立した Vite + TypeScript プロジェクトです。
使いたいフォルダに入って起動してください。

```bash
# おみくじ
cd omikuji
npm run dev

# ドット絵ペイント
cd paint
npm run dev
```

表示された `http://localhost:5173/` のような URL をブラウザで開きます。
（`npm install` は配布時に済ませてあります。未インストールなら各フォルダで一度だけ `npm install` してください。）
