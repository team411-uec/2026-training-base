# おみくじアプリ（GUI 版ベース）

研修の最終成果物のための **ベース（土台）** です。
このままでも一応動きますが、**わざと「未完成」の状態**にしてあります。
まずはステップ1を完成させ、そのあとチームで自由に拡張していってください。

---

## 起動方法

```bash
npm run dev
```

実行すると `http://localhost:5173/` のような URL が表示されるので、ブラウザで開いてください。
（`npm install` は講師が済ませた状態で配布しています。もし未インストールなら一度だけ `npm install` してください。）

---

## まず触ってみよう（ステップ0：配布状態）

1. ブラウザで開いて「おみくじを引く」を押す。
2. 画面の文字は **「ここに結果が出ます」のまま変わりません**。
3. でも、ブラウザの開発者ツール（`F12` キー →「Console」タブ）を見ると、
   `引いた結果: 大吉` のように **結果がちゃんと出ています**。

→ つまり「おみくじを引くロジック」は完成して動いています。
　 足りないのは「**結果を画面に表示する**」部分だけです。これが最初の課題です。

---

## 全体の構成（3層に分かれています）

画面は `index.html` の1枚。プログラムは役割ごとに3つのファイルに分割しています。

| ファイル | 層 | 役割 | 状態 |
| --- | --- | --- | --- |
| `src/omikuji.ts` | データ層 | おみくじの型・比率・箱(OmikujiBox)クラス | 完成済み |
| `src/render.ts` | 描画層 | 状態を画面(DOM)に表示する | **空（ステップ1で実装）** |
| `src/main.ts` | イベント層 | ボタンと処理を結びつける配線 | 完成済み |

CLI 版（小まとめ）からの対応関係：

- キーボード入力待ちの `while` + `readline` → **ボタン + `addEventListener`**（`main.ts`）
- `console.log("...が出ました")` → **`textContent` で画面に表示**（`render.ts`）

---

## ステップ1（必修）：結果を画面に表示しよう

`src/render.ts` の `renderResult` 関数が空っぽなので画面が変わりません。
この中身を実装してください。

やること：

1. `document.getElementById("result")` で結果表示の要素を取得する。
2. その要素の `textContent` に、引いた結果（`result`）を入れる。
3. `result` が `null` のとき（リセット直後など）は、初期メッセージを表示する。

うまくいけば、「おみくじを引く」を押すたびに画面の文字が切り替わります。
詳しいヒントは `src/render.ts` のコメントに書いてあります。

## ステップ2以降：自由に拡張しよう（難易度別の例）

ここからはチームの自由です。下は「何をすればいいか分からない人」向けの例です。
好きなものを選んでも、まったく別のアイデアでも構いません。

### 易（HTML / CSS 中心）

- 結果やボタンの文言・色を変える（`index.html` の `<style>`）。
- `index.html` の `<style>` に `.omikuji-result[data-result="大吉"] { background-color: gold; }` を足して、
  **大吉のときだけ見た目を変える**。
  （`render.ts` で `el.dataset.result = result;` を書いておく必要があります）

### 中（DOM 操作中心）

- **引いた履歴をリスト表示**する。
  `render.ts` に履歴用の関数を足し、`createElement("li")` で項目を作って
  `<ul id="history">` に `appendChild` していく。`main.ts` 側で結果を配列に `push` して渡す。
- リセットを押した回数を数えて画面に出す。

### 難（型・クラス・設計）

- **残りくじ枚数を表示**する。
  `omikuji.ts` の `OmikujiBox` に「残り枚数を返すメソッド」を足してから、`render.ts` で表示する。
  （`tickets` は `private` なので、外から数えるのではなく **箱にメソッドを足す** のがポイント）
- **比率を画面から変更できる UI**（`input` 要素）を作る。
  入力値を `Number()` で読み取り、`reset` が比率を受け取れるように改修する。
- **おみくじの種類を増やす**（例: 半吉）。
  `omikuji.ts` の `OmikujiResult` 型に `"半吉"` を足し、`omikujiRatios` にも個数を足すだけ。

各ファイルには `★拡張ポイント` というコメントがあります。そこを手がかりに進めてください。

## 使ってよい技術・避ける技術

研修で学んだ範囲だけで作れるようにしています。

- 使うもの：TypeScript（型・クラス・関数・ファイル分割）、基本の HTML タグ、
  DOM 操作（`getElementById` / `textContent` / `createElement` / `appendChild` など）、`addEventListener`。
- 避けるもの：React/Vue などのフレームワーク、`flex`/`grid` を使った複雑なレイアウトの自作、
  クラスの継承（`extends`）、`alert` などのポップアップ。
