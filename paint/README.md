# ドット絵ペイント（GUI 版ベース）

研修の最終成果物のための **ベース（土台）** です。
このままでも一応動きますが、**わざと「未完成」の状態**にしてあります。
まずはステップ1を完成させ、そのあと個人・チームで自由に拡張していってください。

---

## 起動方法

```bash
cd paint
npm run dev
```

実行すると `http://localhost:5173/` のような URL が表示されるので、ブラウザで開いてください。
（`npm install` は講師が済ませた状態で配布しています。もし未インストールなら一度だけ `npm install` してください。）

---

## まず触ってみよう（ステップ0：配布状態）

1. ブラウザで開くと、16×16 のマス目が表示されます。
2. マスをクリックしても、**色は変わりません**。
3. でも、ブラウザの開発者ツール（`F12` キー →「Console」タブ）を見ると、
   `塗ったマス: 5` のように **クリックした場所がちゃんと出ています**。

→ つまり「塗るデータの処理」は完成して動いています。
　 足りないのは「**マスに色をつけて画面に反映する**」部分だけです。これが最初の課題です。

---

## 全体の構成（3層に分かれています）

画面は `index.html` の1枚。プログラムは役割ごとに3つのファイルに分割しています。

| ファイル | 層 | 役割 | 状態 |
| --- | --- | --- | --- |
| `src/canvas.ts` | データ層 | 各マスの色を持つ箱(PixelCanvas)クラス | 完成済み |
| `src/render.ts` | 描画層 | 状態を画面(DOM)に表示する | `renderGrid` は完成 / **`renderCell` は空（ステップ1）** |
| `src/main.ts` | イベント層 | クリックと処理を結びつける配線 | 完成済み |

---

## ステップ1（必修）：クリックしたマスを塗ろう

`src/render.ts` の `renderCell` 関数が空っぽなので色が変わりません。
この中身を実装してください。

やること：

1. `document.getElementById(`cell-${index}`)` で、色を変えたいマスの要素を取得する。
2. その要素の `style.backgroundColor` に `color` を入れる。

うまくいけば、クリックでマスが黒くなり、「全消去」で白に戻ります。
詳しいヒントは `src/render.ts` のコメントに書いてあります。

## ステップ2以降：自由に拡張しよう（難易度別の例）

ここからは自由です。下は「何をすればいいか分からない人」向けの例です。
好きなものを選んでも、まったく別のアイデアでも構いません。

### 易（HTML / CSS / 定数）

- 塗る色を変える（`src/canvas.ts` の `DEFAULT_COLOR`）。
- マス数を変える（`src/canvas.ts` の `GRID_SIZE`。CSS の `.pixel-canvas` の幅も合わせる）。
- マスや背景の見た目を変える（`index.html` の `<style>`）。

### 中（DOM 操作）

- **カラーパレット**：色ボタンを並べて、押した色を「今の色」として塗れるようにする
  （`main.ts` で固定の `DEFAULT_COLOR` ではなく、選んだ色を使う）。
- **消しゴム**：白(`EMPTY_COLOR`)で塗るモードを作る。

### 難（アルゴリズム・設計）

- **バケツ塗り（塗りつぶし）**：クリックしたマスとつながった同色のマスをまとめて塗る。
- **Undo / Redo**：塗った操作を配列で記録して、元に戻す・やり直す。
- **アニメーション**：複数フレームを作って、パラパラマンガのように切り替える。
- **保存・再現**：描いたドット絵を保存して、あとで読み込んで再現する
  （保存先の仕組みは研修範囲外なので、各自調べながら挑戦してみましょう）。

各ファイルには `★拡張ポイント` というコメントがあります。そこを手がかりに進めてください。

> チームで開発するなら、「カラーパレット担当」「Undo/Redo 担当」「アニメ担当」のように
> 機能ごとに分担することもできます（任意）。

## 使ってよい技術・避ける技術

研修で学んだ範囲だけで作れるようにしています。

- 使うもの：TypeScript（型・クラス・関数・ファイル分割）、基本の HTML タグ、
  DOM 操作（`getElementById` / `createElement` / `appendChild` / `style` など）、`addEventListener`。
- 避けるもの：React/Vue などのフレームワーク、`flex`/`grid` を使った複雑なレイアウトの自作、
  クラスの継承（`extends`）、`alert` などのポップアップ。
