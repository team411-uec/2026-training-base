# ドット絵ペイント（GUI 版ベース）

研修の最終成果物のためのベース（土台）です。
土台の骨組みに加えて、色を塗るデータ処理（データ層）と、クリックを受け取って動かす部分（イベント層）はすでに完成して動いています。
残っているのは、クリックしたマスに色をつけて画面に反映する部分だけです。
まずはステップ1でそこを完成させ、そのあと個人・チームで自由に拡張してください。

---

## 初回セットアップ

```bash
npm install
```

## 起動方法

```bash
npm run dev
```

表示された `http://localhost:5173/` のような URL をブラウザで開いてください。
（リポジトリの取得手順は別の資料にまとめてあります。）

---

## まず触ってみよう（ステップ0：配布状態）

1. ブラウザで開くと、16×16 のマス目が表示される。
2. マスをクリックしても、色は変わらない。
3. しかし開発者ツール（`F12` →「Console」タブ）を見ると、`塗ったマス: 5` のようにクリックした場所が出ている。

塗るデータの処理は完成して動いています。
足りないのは、マスに色をつけて画面に反映する部分だけです。これが最初の課題です。

---

## 全体の構成（3層に分かれています）

画面は `index.html` の1枚。プログラムは役割ごとに3つのファイルに分けています。

| ファイル | 層 | 役割 | 状態 |
| --- | --- | --- | --- |
| `src/canvas.ts` | データ層 | 各マスの色の情報を持ち、塗る関数を提供する | 完成済み |
| `src/render.ts` | 描画層 | 状態を画面(DOM)に表示する | `renderGrid` は完成 / `renderCell` は空（ステップ1） |
| `src/main.ts` | イベント層 | クリックと処理を結びつける | 完成済み |

---

## ステップ1（必修）：クリックしたマスを塗ろう

`src/render.ts` の `renderCell` が空なので色が変わりません。ここを実装します。

やること:

1. 色を変えたいマスの要素を取得する。
2. その要素の背景色を、渡された `color` に変える。

うまくいけば、クリックでマスが黒くなり、「全消去」で白に戻ります。
ヒントは `src/render.ts` のコメントにあります。

---

## ステップ2以降：自由に拡張しよう（難易度別の例）

ここからは自由です。下は例なので、別のアイデアでも構いません。

### 易（HTML / CSS / 定数）

- 塗る色を変える（`src/canvas.ts` の `DEFAULT_COLOR`）。

### 中（DOM 操作）

- カラーパレット: 色ボタンを並べて、押した色を「今の色」として塗れるようにする（`main.ts` で固定の `DEFAULT_COLOR` ではなく、選んだ色を使う）。

### 難（アルゴリズム・設計）

- Undo / Redo: 塗った操作を配列で記録して、元に戻す・やり直す。

各ファイルには「拡張ポイント」というコメントがあります。そこを手がかりに進めてください。

チームで開発するなら、「カラーパレット担当」「Undo/Redo 担当」のように機能ごとに分担することもできます（任意）。
