### 事前準備: 乱数の使い方

まずは本格的に実装していく前に、事前準備として乱数の使い方について示します。

**(難しいと感じた場合は下の「簡易おみくじアプリの解答」まで飛んで、使い方を学んでも大丈夫です。)**

TypeScriptでは以下のように乱数を生成します。

```ts
const rnd = Math.random();
console.log(rnd);
// 実行結果: 0.7432225613499299
```

乱数を生成している部分は `Math.random()` です。MathはTypeScriptの組み込みオブジェクトと呼ばれるもので、
クラスのように new でインスタンス化することなく、そのまま直接呼び出して使用できます。

`Math.random` 関数は、0から1までの間のランダムな小数の値を出力します。
この関数の結果は、プログラムを実行するたびに毎回値が変わります。

この関数を利用して配列の中からランダムな要素を抽出するプログラムを作りたいのですが、
配列の番号をランダムに指定するときは、0から(配列の要素数-1)番目までの要素番号を乱数生成しなければなりません。

このようなときは、randomの値を要素数(n)倍して切り捨てることをします。
例えば0から9までの値をランダムに生成する場合は以下のように書きます。

```ts
const n = 10;
const randomIdx = Math.floor(Math.random() * n);
```

つまりnを配列の長さに指定してあげると配列からランダムな値を取り出すことができます。

それでは、`["大吉", "中吉", "小吉", "吉", "末吉", "凶"]` のように格納された配列から、ランダムに要素を抽出して表示するプログラムを作ってみてください。

<details>
<summary>簡易おみくじアプリの解答</summary>

配列の要素数は `array.length` で取ってこれます。

```ts
const main = () => {
  const omikuji = ["大吉", "中吉", "小吉", "吉", "末吉", "凶"];
  const randomIdx = Math.floor(Math.random() * omikuji.length);
  console.log(omikuji[randomIdx]);
};

main();
```

</details>

## 本格的なおみくじアプリを実装する

上記では非常に簡単な簡易的なおみくじアプリを実装しましたが、今度はクラスなどを活用して本格的なおみくじアプリを作ってみましょう。

今回は以下のようにおみくじアプリの要件定義をしてみます。

- おみくじの結果の型を用意する
- `OmikujiBox` (おみくじ箱) クラスを用意する
- おみくじ箱に有限個のおみくじを用意する `reset` メソッドを持たせる
- おみくじを引く `draw` メソッドを用意し、おみくじ箱からランダムに引けるようにする
- おみくじの大吉～凶までは、比率を選べるようにする
- ユーザー入力でおみくじの操作をできるようにする

具体的な動作イメージとしては以下のようなものを作ります。

```text
おみくじアプリ
入力してください (Enter: おみくじを引く、 r: リセット、 q: 終了) >>

おみくじを引きます
「中吉」が出ました！

入力してください (Enter: おみくじを引く、 r: リセット、 q: 終了) >>

おみくじを引きます
「大吉」が出ました！

```

### 1. クラスの設計

まずは **OmikujiBox クラス** の設計を考えてみましょう。

クラスを作るということは、 **プロパティ(保持するデータ)とメソッド(機能)** をひとまとめにするということです。

今回のおみくじ箱には、どのようなプロパティとメソッドを持たせればよいでしょうか。要件定義を見ながら、少し考えてみてください。
ヒントは、プロパティが1つ、メソッドが2つになります。

<details>
<summary>クラス設計の解答</summary>

おみくじ箱に必要な要素は以下のようになります。

プロパティ

- 箱の中に入っているおみくじの情報を保持する配列

メソッド

- 箱の中に決められた比率でおみくじをセットする（reset）
- 箱の中からランダムに1枚おみくじを引き、箱から減らす（draw）

</details>

### 2. ファイルの分割と型の定義

以前の研修ではファイル分割の手法を学習しました。
今回も同様に、ファイルを次の2つに分割します。

- `omikuji.ts`: おみくじの型と OmikujiBox クラスを定義するファイル
- `main.ts`: クラスを読み込んで、実際にアプリを動かすファイル

ここで、`omikuji.ts` ファイルではおみくじの型を用意してあげる必要があります。

まずは omikuji.ts を作成し、他ファイルから読み込めるように export を使って型と比率を定義します。
少し難しいですが、まずはコードを示します。

```ts
// omikuji.ts
export type OmikujiResult = "大吉" | "中吉" | "小吉" | "吉" | "末吉" | "凶";

export const omikujiRatios: Record<OmikujiResult, number> = {
  大吉: 5,
  中吉: 15,
  小吉: 20,
  吉: 30,
  末吉: 20,
  凶: 10,
};
```

`OmikujiResult` ではstring型で大吉～凶を表しているように見えますね。

`omikujiRatios` では、`OmikujiResult` で表された各要素に対して個数を書いています。

ここで、以前学習したファイル分割について活用されています。
そのまま変数や型を定義しても今回の場合は `omikuji.ts` ファイル以外では使用できませんが、
宣言時に `export` を付けると他のファイルでも扱えるようになります。

ここまでは学習済みですが、今回はTypeScript特有の機能を使用して少し難しくなっています。
順番に説明すると、まず前半の

```ts
export type OmikujiResult = "大吉" | "中吉" | "小吉" | "吉" | "末吉" | "凶";
```

の部分は、OmikujiResultという型を用意しています。
これは、本来はOmikujiResultは `string` を表すものですが、
このように大吉～凶まで `|` で区切って文字列を並べると、
**文字列ではあるがこの6つの文字列以外は認めないという型**を作ることができます。(Union Typeといいます。)

これは、文字列で大吉～凶までを管理するときに、存在しない文字列や打ち間違い(「第吉」など)を入力したときにエラーが出るようになって、間違えにくくなります。

次に後半部分について見ていきます。

```ts
export const omikujiRatios: Record<OmikujiResult, number> = {
  大吉: 5,
  中吉: 15,
  小吉: 20,
  吉: 30,
  末吉: 20,
  凶: 10,
};
```

1行目は、`omikujiRatios` という定数が、`Record<OmikujiResult, number>` という型になっているということを表しています。
これは、`OmikujiResult` (さきほどの大吉～凶までの文字列) と、数値型がセットになったRecordです。
つまり、大吉～凶までのそれぞれの文字列に対応した「くじの個数」をnumberで対応させた情報を記録した定数の型となります。
2行目以降では、例えば大吉が5個、中吉が15個、...のように個数を決めています。(数値自体は何でもよいです。)

### 3. OmikujiBox クラスの実装

続いて、同じ omikuji.ts の中にクラスを実装していきます。
まずはクラスの定義を上記で型を定義した `omikuji.ts` の下に書いていきましょう。

`OmikujiBox` クラスを用意し、その中におみくじの箱の中身 `tickets` 、コンストラクター、`reset` メソッド、`draw` メソッドを作ります。

```ts
// omikuji.ts
export class OmikujiBox {
  private tickets: OmikujiResult[] = [];

  constructor() {
    // ここに初期化処理
  }

  public reset(): void {
    // ここにリセットの処理
  }

  public draw(): OmikujiResult | null {
    // ここにおみくじを引く処理
  }
}
```

クラスの内部だけで扱うデータはカプセル化します。
カプセル化とは、内部のプロパティやメソッドを外部から隠し、不用意に触られないようにすることです。

`tickets` に対しては外部から直接操作されてしまっては困るので、`private` を付けます。

`reset` や `draw` など外部から呼び出したいメソッドには `public` をつけます。

`constructor` は、クラスが初めに使用される(インスタンスが作成された)ときに1度のみ実行されるものです。

続いて定義した `reset` メソッドは、引数は何も受け取らず、戻り値もなし(`void`) で作ります。

`draw` メソッドは、引数は何も受け取らず、戻り値は、`OmikujiResult` または `null` が返されます。正常におみくじを引くことができれば大吉～凶の文字列のいずれかである `OmikujiResult` の文字列が返されますが、
おみくじ箱が空(ticketsの長さが0)であったときには何も引けないので `null` を返すようにする設計とします。

<details>
<summary>余裕のある人向け：クラス設計の観点から</summary>

`private` は「このクラスの中だけで使うデータなので、外から勝手に触らないでね」という意味です。

ここで初心者がやりがちなのが、クラスの外側（`main.ts` など）からおみくじの箱の中身（配列）を見に行って、外側で判断して、外側で配列操作までしてしまうことです。

#### アンチパターン：外側が「箱のルール」を知ってしまう

もし箱の中身を外から直接触れる設計だと、例えば次のようなことが起きます。

- `main.ts` が「箱が空かどうか」を毎回チェックしないといけない
- `main.ts` が「引いたら1枚減らす」を自分で実装しないといけない
- 別の場所でも同じ処理を書き始めて、挙動がズレる（バグの原因になる）

つまり、**本来は箱が責任を持つべきルール**が、外側に散らばってしまいます。

#### 良い設計：クラスに「やってほしいこと」を頼む

今回の `OmikujiBox` で外側が本当にやりたいのは、「箱の中身を細かく操作すること」ではなく次の2つです。

- `reset()`：おみくじを用意し直してほしい
- `draw()`：ランダムに1枚引いてほしい（空なら「引けない」と教えてほしい）

このように、外側は **「どうやって実現するか」を知らなくてよくて**、  
クラスに **「これをやって」** とお願いできれば十分です。

> まとめ：`private` にする目的は「隠すこと」そのものではなく、  
> **ルール（処理）をクラスの中にまとめて、外側をシンプルにすること**です。

（※ 1年後期の基礎プログラミングの授業でクラスの中身を読むための仕組み（アクセサ）も出てきますが、まずは「中身を直接触らず、操作をお願いする」が基本になります。）

今の時代では簡単なクラスのコードならAIに頼んで書いてもらうこともできます。
しかし、今後それなりの規模で沢山クラスを作成していくと、必ずと言っていいほどクラス設計の難しさの壁にぶつかります。

もちろんそこもAIに頼ることもできますが、AIはさらっと今の時代の最善の実装（ベストプラクティス）を提示するか、もしくはとりあえず動くだけの設計的によろしくないコードを提示するかのどちらかになりがちです。
クラス設計の基本的な考え方を理解していないとAIに書いてもらったコードを理解できず、触って壊すのが怖くなり、結局自分で修正したり作り直したりすることができないままコード量だけが膨らんで手遅れになってしまう可能性もあります。

今回はそこまで深いクラス設計の話はしませんが、皆さんの今後のプログラミング学習のためにもこういったコーディングより1段階上の設計という観点も少し意識してみてはいかがでしょうか。

</details>

それでは、`reset` メソッドの中身から作っていきましょう。constructor内で `reset` を呼び出すことで、インスタンス作成時に初期化されるようにもしておきます。

```ts
// omikuji.ts
export class OmikujiBox {
  private tickets: OmikujiResult[] = [];

  constructor() {
    this.reset();
  }

  public reset(): void {
    this.tickets = [];

    for (const [result, count] of Object.entries(omikujiRatios)) {
      for (let i = 0; i < count; i++) {
        this.tickets.push(result as OmikujiResult);
      }
    }
    console.log(
      `おみくじ箱をリセットしました。（合計 ${this.tickets.length} 枚）`,
    );
  }

  public draw(): OmikujiResult | null {
    // ...
  }
}
```

`this.xxx` や `this.yyy()` とすると同じクラス内の変数やメソッドを使用できます。

`reset` の `for` 文2つについて詳しく見ていきます。

```ts
for (const [result, count] of Object.entries(omikujiRatios)) {
  for (let i = 0; i < count; i++) {
    this.tickets.push(result as OmikujiResult);
  }
}
```

`omikujiRatios` は `Record<OmikujiResult, number>` 型でした。これに `Object.entries()` を施すと、
それぞれ 「`OmikujiResult` とそれに対応する `number` が格納された配列」の配列が返されます。

今回上記で定義した `omikujiRatios` 定数の結果では、
entriesの戻り値は `[["大吉", 5], ["中吉", 15], ["小吉", 20], ...]` のような二次元配列が得られます。
これをofを使って、左側を `result` 、右側を `count` として取り出しています。

※ `Object.entries` を使うとキーが単なる文字列（`string`）として認識されてしまうため、`this.tickets.push` する際に `as OmikujiResult` を使って元の正しい型に戻してあげています。

さらに内側のfor文では、それぞれの `result` と `count` について、
`count` 回数分(omikujiRatiosで設定した個数分)、`tickets` 配列に `result` を追加しています。

最終的にticketsは `["大吉", "大吉", "大吉", "大吉", "大吉", "中吉", "中吉", "中吉",..., "凶"]`
のようにそれぞれの個数分の文字列が追加されることになります。

最後に、`draw` メソッドを実装して完成させましょう。

```ts
// omikuji.ts
export class OmikujiBox {
  // ...

  public draw(): OmikujiResult | null {
    if (this.tickets.length === 0) {
      console.log("もうおみくじは空っぽです！リセットしてください。");
      return null;
    }

    const randomIdx = Math.floor(Math.random() * this.tickets.length);
    const drawnTicket = this.tickets.splice(randomIdx, 1)[0];
    return drawnTicket;
  }
}
```

さきほど決めた通り、`tickets` に何も入っていない場合は空っぽであることを返します。

それ以外の場合は、`randomIdx` で `tickets` 中の要素中からランダムに1つ要素番号を決めます。
配列には `splice` メソッドが用意されており、以下のような仕様となっているのでこれを用います。

```ts
配列.splice(抜き出す要素の初めの要素番号, 抜き出す要素の個数);
```

このメソッドの戻り値は抜き出された要素を集めた配列となります。よって、
引数にそれぞれ `randomIdx`、1を指定した後その戻り値の0番目を取り出すという処理をすることで、
おみくじ箱からくじを引く処理が実装できます。

### 4. メイン処理の実装

最後に `main.ts` を作成します。

ここではターミナルからユーザーのキーボード入力を受け取るために、`readline/promises` を使います。
async awaitなどが使用されていますが、これは入力を受け付けるために必要な記述です。
これらを非同期処理と呼びますが、今回の処理とはあまり関係がないので、おまじないとして入力してください。

```ts
// main.ts
import * as readline from "readline/promises";
import { stdin as input, stdout as output } from "process";

import { OmikujiBox } from "./omikuji";

const main = async () => {
  const box = new OmikujiBox();

  const rl = readline.createInterface({ input, output });

  console.log("おみくじアプリ");

  while (true) {
    const answer = await rl.question(
      "\n入力してください (Enter: おみくじを引く、 r: リセット、 q: 終了) >> ",
    );

    if (answer.toLowerCase() === "q") {
      console.log("終了します。");
      break;
    } else if (answer.toLowerCase() === "r") {
      box.reset();
    } else {
      const result = box.draw();
      if (result) {
        console.log(`「${result}」が出ました！`);
      }
    }
  }
  rl.close();
};

main();
```

`readline.createInterface()` は、入出力を受け付けるための準備です。
`await rl.question()` は、ここで画面にメッセージを表示し、ユーザーの入力を待ちます。
入力された文字は変数 `answer` に格納されるので、その文字が「q（終了）」なのか「r（リセット）」なのか、「Enter（おみくじを引く）」なのかを if 文で判定して、クラスのメソッド（reset や draw）を呼び出しています。

このように、型やクラスを定義するファイルと、それらを組み合わせて動かすファイルを分割することで、コードが読みやすく管理しやすくなります。
これがファイル分割とクラスの大きなメリットです。
